# `first_task.c` — решение СЛАУ методом Крамера

## Назначение

Программа решает систему линейных алгебраических уравнений вида `Ax = b` методом Крамера для матрицы произвольной размерности `NxN`.

## Особенности реализации

- Матрица коэффициентов хранится как `double **matrix`;
- столбец свободных членов хранится как `double *free_terms_vector`;
- определитель матрицы считается рекурсивным разложением по строке:
  - `find_determinant` — вычисляет определитель матрицы;
  - `find_minor_determinant` — рекурсивно вычисляет определитель минора;
  - `get_multiplier` — возвращает алгебраический знак `+1` или `-1`;
- неизвестные находятся через метод Крамера:
  - столбец матрицы поочерёдно заменяется столбцом свободных членов;
  - для каждой замены считается определитель;
  - неизвестная вычисляется как `det_i / det`;
- реализована функция `find_unknowns`, которая сохраняет и восстанавливает заменяемый столбец.

## Формат ввода

Программа запрашивает в консоли:

1. размерность матрицы `N`;
2. элементы матрицы `A` размера `NxN`;
3. столбец свободных членов `b`.

# `hard_task.c` — проверка решения судоку

## Назначение

Программа проверяет, является ли заполненная квадратная матрица корректным решением судоку.

Проверяются три правила:

- каждая строка содержит числа `1..N` без повторений;
- каждый столбец содержит числа `1..N` без повторений;
- каждый малый квадрат `small_square_size x small_square_size` содержит числа `1..N` без повторений.

## Особенности реализации

- матрица читается из файла `input.txt`;
- реализованы отдельные проверки:
  - `check_rows` — проверка строк;
  - `check_columns` — проверка столбцов;
  - `check_squares` — проверка малых квадратов;
- объединяющая функция в коде называется `check_for_sudoku` (по заданию — `is_valid_sudoku`);
- для отметок уже встреченных чисел используется массив `bool *used_numbers`;
- функция `clear_used` сбрасывает массив отметок перед проверкой очередной строки, столбца или квадрата.

## Формат `input.txt`

Файл должен содержать:

1. размерность матрицы `N`;
2. размер малого квадрата `small_square_size`;
3. `N * N` целых чисел — элементы матрицы.
