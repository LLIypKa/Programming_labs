# `hard_task.c` — взлом шифра Цезаря

## Назначение

Программа реализует взлом шифра Цезаря без знания сдвига. Она перебирает все 26 возможных сдвигов, для каждого расшифровывает текст и считает количество букв `e` и `t` (в обоих регистрах). Побеждает сдвиг, при котором этих букв больше всего.

## Особенности реализации

- программа читает текст из стандартного ввода до `EOF`;
- для накопления строки используется `realloc`;
- реализованы функции:
  - `find_offset_and_decrypt` — перебирает сдвиги, выбирает лучший и возвращает его;
  - `decrypt_with_any_offset` — расшифровывает строку с заданным сдвигом;
  - `check_symbols` — считает количество букв `e` и `t` (в обоих регистрах);
- поддерживаются заглавные и строчные латинские буквы;
- остальные символы (пробелы, цифры, знаки) не изменяются;
- сдвиг может быть отрицательным или больше 26 — берётся по модулю 26;
- шифрование и расшифровка выполняются одной и той же операцией, но с разными знаками сдвига.
