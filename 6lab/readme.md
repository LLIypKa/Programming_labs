first_task.c - реализация задачи на 4 с подсчётом энергии сигнала:
- мнимая и вещественная части комплексного числа хранятся в одной памяти (используется тип unsigned int)
- получение каждой части через отдельные методы, реализовано через сдвиг и побитовое
- подсчёт энергии сигнала через сумму значений отсчётов (которые в свою очередь считаются суммой квадратов частей числа)
- поиск максимума через вещественную часть

second_task.c - задача на 5 (вариант 2, часть 1 (B1))
- реализован поиск максимального по модулю отсчёта (использована limits.h)
- реализован расчёт коэффициента усиления
- реализован метод усиления (нормирования) отсчётов и поиск количества срезанных после двойного усиления
